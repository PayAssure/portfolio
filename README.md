# PayAssure — Portfolio

This workspace now contains a Next.js + TypeScript + Tailwind scaffold for PayAssure.

Quick start:

```bash
# from /home/wilfred/payassure/portfolio
npm install
npm run dev

# then open http://localhost:3000
```

Notes:
- The Next.js app files are in the `pages/` and `components/` folders.
- Tailwind is configured via `tailwind.config.cjs` and PostCSS.

If you'd like, I can remove the old `index.html` static file, wire up a deployment (Vercel/GitHub Pages), or add a proper CI build.
